OdooBot AI

Message OdooBot in plain Arabic or English and it searches, creates and updates records for you.

An LLM (LLaMA 3.3 70B on Groq) reads the conversation and proposes an action. Searches run straight away. Anything that writes is shown as a summary first and is saved only after the user answers yes, with that user's own access rights.

Set the Groq key in Settings > AI Bot (Groq), or in the GROQ_API_KEY environment variable.
